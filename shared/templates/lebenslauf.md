# Lebenslauf Template (tabellarisch)

Skeleton for a German CV. Rules in `shared/references/de-documents.md`.
**1–2 pages, hard maximum 2. Reverse-chronological throughout.**

## Fill rules

| Section | Rule |
|---|---|
| **Foto** | Only if `profile.md` says the candidate wants one. Never ask per job. |
| **Persönliche Daten** | Name, address, phone, email always. Geburtsdatum and Staatsangehörigkeit optional — include only if the candidate opted in. **Never Familienstand, never religion.** |
| **Berufserfahrung** | Newest first. `MM/JJJJ` format. 2–5 bullets; more for recent roles, fewer for old ones. Order bullets by relevance to *this* posting. |
| **Ausbildung** | Include the grade if it is good. Germans expect it. Foreign degrees: add the German equivalent if anabin gives one (`work-authorization.md`). |
| **Sprachen** | CEFR or the conventional label, from `profile.md`. **Never inflate.** |
| **Skills** | Reordered per posting — lead with what the ad asks for. Never add a skill that is not in the profile. |
| **Ort, Datum, Unterschrift** | Expected at conservative employers, optional at startups. Decide from employer type in `language.md`. |

## Traps

- **No Summary, no Objective, no Profile section.** The German Lebenslauf has no narrative header. That is what the Anschreiben is for.
- **No "Referenzen auf Anfrage."** Attach actual Zeugnisse instead.
- **Gaps get labelled, never hidden.** `Elternzeit`, `Weiterbildung`, `Sabbatical`, `Umzug nach Deutschland`, `Arbeitssuche`. Never move a date to close a gap.
- **Titles and dates are never changed.** Reorder and rewrite bullets; never touch the facts.
- **Two pages maximum.** If it runs over, cut bullets from the oldest roles, never a role itself.
